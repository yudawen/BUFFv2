
# BUFFv2

**BUFFv2** is a refined version of the BUFF dataset, containing approximately **668 MB** of data.

The refined dataset is publicly available through Baidu Netdisk:

- **Download link:** https://pan.baidu.com/s/1A3x5iRtPa0zX6HNCsbwe2g
- **Extraction code:** `buff`

We recommend using BUFFv2 for experiments involving building-function classification and building polygon delineation.
